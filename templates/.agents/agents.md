# Antigravity agent persona (legacy path)

Older Antigravity builds read `.agents/agents.md` instead of a root-level
`AGENTS.md`. If that's what you're running, treat this file as a redirect:
read `AGENTS.md` in the repository root and follow it for any prompt that
changes the codebase.

Antigravity releases from 2026 onward read the root `AGENTS.md` directly,
which makes this file unnecessary — delete this `.agents/` directory once
you've confirmed that's the case for your version.
